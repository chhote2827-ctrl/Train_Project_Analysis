# 📊 Sales & Orders Analysis Power BI Dashboard

## 📌 Project Overview
This Power BI dashboard provides an end-to-end analysis of sales, orders, customer behavior, and shipping performance.

## 🚀 Key Features
- **KPI Overview:** Total Sales, Total Orders, Total Customers, and Average Order Value.
- **Trend Analysis:** Sales & Orders trend over time (Yearly/Monthly).
- **Product Breakdown:** Performance analysis by Category & Sub-Category.
- **Geographical Insights:** Interactive map for State-level sales distribution.
- **Shipping Insights:** Distribution of orders across different Ship Modes.
- **Customer Insights:** Top 10 Customers by Total Sales.
- **Interactive Filters:** Date slider, Region, and Category slicers.
